Explicit Telecommute Model

!! info "Model Purpose" 
    The explicit telecommute model determines if person making a mandatory trip is eligble for telecommuting.

## Model Overview

**Number of Models**: 1  
**Decision-Making Unit:** Worker who makes a mandatory activity pattern  
**Model Form:** Binominal Logit  
**Alternatives:** 2 (Yes/No)

### Purpose and Role
The Explicit Telecommute Model determines if a person making a 'mandatory' activity pattern is eligble for telecommuting. If the person is identified as telecommuters in the model, their CDAP results is updated to be non-mandatory or home.  

The model predicts whether a person telecommutes based on the following variables: 

- Employment Type
- Share of Employment
- Household Income
- Type of Worker (Part Time vs Full Time)
