## 🛣️ Highway Network Components

Components for highway network modeling, assignment, and analysis.

!!! abstract "Highway Modeling Workflow"

    2. **MAZ Connectivity**: Connect micro-zones to highway access points

    4. **Performance Analysis**: Calculate travel times, speeds, and congestion

## 📊 Data Models & Validation

Data validation models ensuring input file integrity and consistency.

!!! abstract "Data Validation Philosophy"
    tm2py uses [Pandera](https://pandera.readthedocs.io/) for robust data validation. Data models define expected schemas, data types, and validation rules for all input files.

    For detailed information about input file formats and requirements, see [Input Files Documentation](input/index.md) 📁
